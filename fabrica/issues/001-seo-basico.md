# 001 · SEO básico

Pedido: que la web aparezca bien en Google y que al compartir el link por WhatsApp o LinkedIn se vea una vista previa linda.

- Necesitamos sitemap y robots.txt.
- Al compartir el link tiene que aparecer una imagen con el logo y la frase "Innovación concreta para empresas de Mendoza".
- La imagen tiene que respetar la marca (fondo Tinta, grilla de puntos).
